# HR Analytics Dashboard

## Objective
Employee data ko analyze karke attrition, salary aur workforce insights nikalna.

## Tools Used
- Power BI
- Excel
- Power Query
- DAX

## Dataset
Employee dataset use karke analysis kiya gaya hai.

## Key Insights
- Attrition rate analysis
- Department-wise employee distribution
- Salary trends
- Gender and age analysis

## Result
Interactive dashboard banaya gaya jo HR decision making me help karta hai.
